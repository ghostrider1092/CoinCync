## Verification protocol before fixing

Per the project standing rule: **subagent findings have a ~50% false-positive rate on file:line specifics. Read the cited line in source before opening a fix PR.** Pattern:

1. Pick an item from the punch list
2. Open the file at the cited line
3. Confirm the issue is real, not a misread of the surrounding code
4. If real: open a focused fix PR (one item per PR is fine; keep them reviewable)
5. If false positive: strike it from this doc with a one-line note explaining why

This doc lives at `docs/v1.0-base-chain-hardening-punchlist.md` — update it in place as items are verified, fixed, or struck.
