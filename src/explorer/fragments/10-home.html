Testnet hard fork. Activates at testnet height 13,000 (~2026-07-05). CIP-007 Mode A — static-height flag day, no signaling window. All five rules are tightening: honest miners producing well-formed blocks pre-activation continue to produce valid blocks post-activation. Please upgrade all nodes to v1.0.12-rc3 by 2026-07-03.
  • encrypted_amount tightened to exactly 8 bytes (no over/under-size acceptance).
  • Per-output size caps enforced at block validation, not just mempool admission.
  • Duplicate stealth addresses rejected within a tx — closes the same-output-twice class of malleability.
  • Cross-tx stealth-address dedup within a block — prevents two txs in the same block from colliding on a stealth output.
  • Ring-size enforcement via monotonic total_outputs_ever(), so ring decoys cannot reference future outputs.
