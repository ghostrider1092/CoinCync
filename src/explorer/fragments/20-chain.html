CLSAG ring signature What is this?
Every CYNC transaction signs with a ring of 11 public keys. One is the real signer. The other 10 are decoys pulled from the chain. Even the network operators cannot tell which one spent. The ring signature mathematically proves one of these signed the transaction — without revealing which.

🗨 Stealth Addresses LIVE
What it's for: Sender derives a fresh one-time output address from the receiver's view+spend keys via ECDH. Two payments to the same recipient share no on-chain link — the receiver scans for outputs only their view key recognizes.
⚖ Pedersen Commitments LIVE
What it's for: Each amount is encoded as C = aG + rH with a random blinding factor r. The chain verifies inputs sum equals outputs sum without ever seeing the values — perfect hiding, computationally binding.
🛡 Bulletproofs+ LIVE
What it's for: Logarithmic-size range proof showing the hidden amount lies in [0, 2) without revealing it. Stops a sender from forging coins via integer overflow. ~672 bytes per output, verifies in single-digit milliseconds.
🌿 Dandelion++ LIVE
What it's for: Each transaction relays through a randomized stem of 1–3 peers before flooding the rest of the network (the "fluff" phase). An adversary watching gossip sees the broadcast but cannot trace the IP origin.
⚡ Spark Protocol DISABLED
What it's for: Lelantus Spark accumulator provides full sender + receiver + amount privacy with no ring decoys. Spent serial numbers prevent double-spends. Phase-2 module — disabled on testnet, scheduled for mainnet activation.
🌳 Shielded Pool (Orchard/Halo2) DISABLED
What it's for: Zcash Orchard shielded pool with recursive Halo2 zk-SNARKs — no trusted setup ceremony needed. Phase-2 module — disabled on testnet, optional opt-in pool for mainnet.
FROST M-of-N Multi-sig NEW
What it's for: Threshold Schnorr signatures (RFC 9591). M-of-N participants each hold one secret share; the coordinator routes round-1 commitments and round-2 signature shares but never holds a key. The aggregate output is indistinguishable from a single-sig — observers can't tell on-chain that this was multi-sig.
⚛ CYNC↔BTC Atomic Swap NEW
What it's for: Trustless CYNC↔BTC trade via adaptor signatures. Both chains' spend transactions commit to the same secret; redeeming one chain reveals the secret, letting the counterparty redeem the other. Either party times out and refunds if the counterparty stalls. No exchange, no escrow, no listing required.
📡 Light-wallet SPV NEW
What it's for: Mobile-friendly SPV. Server returns per-block view-tag digests (~138 B per output); the wallet scans locally with its view key. The server never learns which addresses you watch — strictly stronger privacy than Bitcoin's BIP-157 compact filters.
⛓ Rolling Soft-Finality QUEUED
What it's for: Active miners (those who mined in the last ~10 000 blocks) attest to recent tip-LAG blocks with ed25519 signatures. ⌈2/3⌉ attestations soft-finalize that height. Window measured in blocks-not-time so the protocol is immune to time-warp manipulation. Library shipped; validate_block hook activates next phase.
🧪 Dandelion++ Graph Verification NEW
What it's for: Continuous-integration harness that spins up multi-node test graphs and asserts the privacy invariant: each origin chooses exactly one stem peer per epoch. Catches regressions where a code change would accidentally fan out at the stem stage and leak the origin IP.
