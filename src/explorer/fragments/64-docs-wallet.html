CoinCync Wallet Guide

This guide covers the CoinCync command-line wallet (cync-wallet).

Overview

The CoinCync wallet provides:

  • Secure key management with BIP39 mnemonics
  • Transaction sending and receiving
  • Balance tracking and history
  • Subaddress management for privacy
  • Confidential asset operations (issue, send, audit)
  • Testnet faucet for free test coins
  • View key export for compliance
  • Name registration (.cync names)
  • TLS-encrypted RPC connections
  • Interactive shell mode

Getting Started

Creating a New Wallet

# Create a new wallet (named "mywallet")
cync-wallet --wallet mywallet --password <pass> --network testnet create

# You will receive:
# 1. A 24-word seed phrase — WRITE IT DOWN AND STORE SECURELY
# 2. Your primary wallet address (tCYNC... for testnet)

Restoring a Wallet

# Restore from seed phrase
cync-wallet --wallet mywallet --password <pass> --network testnet restore
# You will be prompted to enter your 24-word seed phrase

Multi-Wallet Support

You can manage multiple wallets by using different --wallet names:

cync-wallet --wallet savings --password <pass> --network testnet create
cync-wallet --wallet spending --password <pass> --network testnet create

# Each wallet is stored as a separate file (savings.cync, spending.cync)

Basic Operations

Sync with a Node

Before checking balances or sending, sync your wallet with a running node:

cync-wallet --wallet mywallet --password <pass> --network testnet \
  --daemon 127.0.0.1:28081 sync

Check Balance

cync-wallet --wallet mywallet --password <pass> --network testnet balance

# Output:
# Balance: 123.456789012345 CYNC
# Unlocked: 120.000000000000 CYNC
# Locked: 3.456789012345 CYNC (requires 10 more confirmations)

Get Your Address

cync-wallet --wallet mywallet --password <pass> --network testnet address

# Output:
# tCYNCxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Send CYNC

# Send to an address
cync-wallet --wallet mywallet --password <pass> --network testnet \
  --daemon 127.0.0.1:28081 send <address> <amount>

# Examples:
cync-wallet --wallet mywallet --password <pass> --network testnet \
  --daemon 127.0.0.1:28081 send tCYNCabc123... 10.5

# Send to a registered name
cync-wallet --wallet mywallet --password <pass> --network testnet \
  --daemon 127.0.0.1:28081 send alice.cync 50

Transaction History

# Show recent transactions
cync-wallet --wallet mywallet --password <pass> --network testnet history

# Show more transactions
cync-wallet --wallet mywallet --password <pass> --network testnet history --limit 50

# Show specific transaction
cync-wallet --wallet mywallet --password <pass> --network testnet show-tx <txid>

Retry a Failed Transaction

# Retry a transaction that failed to broadcast
cync-wallet --wallet mywallet --password <pass> --network testnet \
  --daemon 127.0.0.1:28081 retry-tx <txid>

Subaddresses

Subaddresses provide unlinkable receive addresses from a single wallet. Each subaddress is cryptographically derived from your main keys but cannot be linked to your primary address or other subaddresses by an outside observer.

Managing Subaddresses

# Generate a new subaddress
cync-wallet --wallet mywallet --password <pass> --network testnet subaddress new

# List all subaddresses
cync-wallet --wallet mywallet --password <pass> --network testnet subaddress list

# Label a subaddress
cync-wallet --wallet mywallet --password <pass> --network testnet \
  subaddress label <index> "Donations"

Use Cases

  • Give each sender a unique address for payment tracking
  • Separate business and personal payments
  • Prevent address-based transaction linking

Testnet Faucet

The testnet faucet dispenses free test coins for development:

# Request testnet CYNC from a faucet-enabled node
cync-wallet --wallet mywallet --password <pass> --network testnet \
  --daemon 127.0.0.1:28081 faucet <your_address>

Rate limit: 1 request per address per hour. Each request dispenses 10 CYNC.

Confidential Assets

CoinCync supports issuing and transferring custom tokens with the same privacy as native CYNC.

Issue a New Asset

# Issue a new asset with a name and initial supply
cync-wallet --wallet mywallet --password <pass> --network testnet \
  --daemon 127.0.0.1:28081 asset issue <asset_name> <supply>

# Example: issue 1,000,000 tokens called "MyToken"
cync-wallet --wallet mywallet --password <pass> --network testnet \
  --daemon 127.0.0.1:28081 asset issue MyToken 1000000

Check Asset Balances

# View all asset balances
cync-wallet --wallet mywallet --password <pass> --network testnet asset balance

Send Assets

# Send an asset to an address
cync-wallet --wallet mywallet --password <pass> --network testnet \
  --daemon 127.0.0.1:28081 asset send <asset_id> <address> <amount>

List and Inspect Assets

# List all known assets on the network
cync-wallet --wallet mywallet --password <pass> --network testnet asset list

# Get info about a specific asset
cync-wallet --wallet mywallet --password <pass> --network testnet asset info <asset_id>

Interactive Shell

For convenience when running multiple commands, use shell mode:

cync-wallet --wallet mywallet --password <pass> --network testnet shell

# In shell mode, run commands without repeating wallet/network flags:
> balance
> address
> send tCYNCabc... 10
> subaddress list
> exit

View Keys

View keys allow you to prove incoming transactions without revealing spending ability.

# Export view key
cync-wallet --wallet mywallet --password <pass> --network testnet export-view-key

# Export to file
cync-wallet --wallet mywallet --password <pass> --network testnet \
  export-view-key --output view_key.txt

# Export for specific epoch (time period)
cync-wallet --wallet mywallet --password <pass> --network testnet \
  export-view-key --epoch 42

Use cases for view keys:

  • Tax reporting
  • Exchange KYC requirements
  • Legal compliance
  • Business auditing

Name Registration

Register a human-readable name for your address:

# Register a name
cync-wallet --wallet mywallet --password <pass> --network testnet \
  --daemon 127.0.0.1:28081 register-name myname

# Your address becomes: myname.cync
# Others can send to: myname.cync instead of tCYNCxxx...

# Name costs:
# 3 characters: 100 CYNC
# 4 characters: 50 CYNC
# 5 characters: 10 CYNC
# 6+ characters: 1 CYNC

TLS Connections

By default, the wallet connects to nodes over TLS. Self-signed certificates are automatically accepted.

# Default: TLS enabled
cync-wallet --wallet mywallet --password <pass> --daemon 127.0.0.1:28081 sync

# Disable TLS (for local development or plaintext nodes)
cync-wallet --wallet mywallet --password <pass> --no-tls --daemon 127.0.0.1:28081 sync

# Pin a specific server certificate (SHA-256 fingerprint)
cync-wallet --wallet mywallet --password <pass> \
  --tls-fingerprint <hex> --daemon 127.0.0.1:28081 sync

UTXOs and Coin Control

# List unspent outputs
cync-wallet --wallet mywallet --password <pass> --network testnet list-utxos

# Send using specific UTXOs
cync-wallet --wallet mywallet --password <pass> --network testnet \
  send <address> <amount> --utxos <txid:index>,<txid:index>

Wallet Security

Encryption

Your wallet file is encrypted using:

  • Argon2id: Memory-hard key derivation
  • XChaCha20-Poly1305: Authenticated encryption

Always use a strong, unique password.

Seed Phrase Security

Your 24-word seed phrase is the master key to your wallet:

  • Write it down on paper (not digitally)
  • Store in multiple secure locations
  • Never share with anyone
  • Never enter on websites

If you lose your seed phrase and wallet file, your funds are lost forever.

Key Epochs

CoinCync uses rotating view keys for forward secrecy:

  • View keys change every ~3.5 days (50,000 blocks)
  • Old view keys cannot see new transactions
  • Limits exposure if a view key is compromised

Best Practices

1. Backup your seed phrase before receiving any funds

2. Use a strong password for wallet encryption

3. Keep software updated for security fixes

4. Verify addresses before sending large amounts

5. Test with small amounts first

6. Use subaddresses for each sender/purpose

7. Use TLS when connecting to remote nodes

Command Line Options

cync-wallet [OPTIONS] <COMMAND>

Options:
  --wallet <NAME>          Wallet name (stored as <name>.cync)
  --password <PASS>        Wallet password
  --network <NETWORK>      Network: mainnet or testnet
  --daemon <HOST:PORT>     Node RPC endpoint
  --no-tls                 Disable TLS for RPC connection
  --tls-fingerprint <HEX>  Pin server certificate (SHA-256)

Troubleshooting

Common Issues

Wallet not syncing:

  • Ensure node is running and synced
  • Check daemon address: --daemon 127.0.0.1:28081
  • If using TLS, try --no-tls to test connectivity
  • Verify network connectivity

Transaction stuck:

  • Wait for network confirmation
  • Use retry-tx to rebroadcast
  • Ensure sufficient fee was paid

Cannot spend funds:

  • Check if outputs are locked (need more confirmations)
  • Verify balance is unlocked
  • Check minimum output age (10 blocks)

TLS connection failed:

  • Try --no-tls for local development
  • Ensure the node has generated its TLS certificate
  • Use --tls-fingerprint for cert pinning if needed

Logs

# Run with debug logging
RUST_LOG=debug cync-wallet --wallet mywallet --password <pass> balance

# Wallet-specific logs
RUST_LOG=coincync::wallet=debug cync-wallet --wallet mywallet --password <pass> balance

Recovery

If your wallet file is corrupted:

# Restore from seed phrase
cync-wallet --wallet mywallet --password <newpass> --network testnet restore

# Rescan blockchain for transactions
cync-wallet --wallet mywallet --password <pass> --network testnet rescan --from-height 0
