Quick start

# Extract
tar xzf coincync-1.0.2-testnet-linux-x86_64.tar.gz

# Run a node (auto-discovers peers)
./coincync-node --network testnet

# Create a wallet
./coincync-wallet create -p YOUR_PASSWORD

# Start mining solo (auto-detects CPU cores)
./coincync-rig run-solo --address YOUR_tCYNC_ADDRESS
